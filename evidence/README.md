# Evidence snapshot

This directory is a copy of the PLM source checkout's research material as observed on 2026-09-25. The source checkout was on `HEAD` `8afff361447b1357a041aa65f5b588af5b7ba5b5` with uncommitted edits, so that commit does not identify the copied bytes by itself. `SHA256SUMS.txt` is the exact inventory of this copy.

- `learning/`: 29 numbered lessons, their overview and figures.
- `experiments/`: declared plans, portable JSON reports and figures.
- `source/`: research/dev logs, protocol/data/architecture/benchmark documents and the symbol registry.
- `pokemon_v1_f1541479_20260924.json`: pinned dataset manifest.

These are archival copies; links from their Markdown into `../src/`, `../configs/` or other source-code directories refer to the separate [PLM source repository](https://github.com/mateors1/Plm-protocolized-language-model-pika-edition). Some links may not resolve in this findings-only repository. The synthesis papers link to copies under this directory where possible. This repository does not contain model checkpoints, protected-test outputs, raw SQLite databases or the full source tree.
