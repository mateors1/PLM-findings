# Model version register

The canonical paper retains its source-relative citation to the full model and checkpoint register. This findings repository provides a source-linked projection for that path; the cited revision is pinned to the [source publication commit](https://github.com/mateors1/Plm-protocolized-language-model-pika-edition/blob/e4121dc13def710d85df02dd55013fdeb67bca68/docs/model-versions.md).

The experiment-specific checkpoint and evaluator identities for `transformer-contribution-v1` are also preserved in the [portable evidence record](../evidence/transformer-contribution-v1/2026-10-20-transformer-contribution-evidence.json). This wrapper does not claim that checkpoint weights are archived here.
